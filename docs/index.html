三数见势｜高岛断事

一个基于“三个数字 + 一个问题”的结构化断事项目。

重点不是空谈吉凶，而是通过固定起卦规则，判断事情当前所处阶段、时势变化、关系节奏，以及下一步更适合怎么推进。

查看 README 查看 Prompt 查看 Rules 查看 Examples

使用方式

输入格式：

三个数字 + 一个问题

例如：

3 8 5 我最近要不要换工作？

起卦规则

上卦

第一个数字决定

÷ 8 取余，余 0 按 8

下卦

第二个数字决定

÷ 8 取余，余 0 按 8

动爻

第三个数字决定

÷ 6 取余，余 0 按 6

八卦数对应

  • 1 = 乾
  • 2 = 兑
  • 3 = 离
  • 4 = 震
  • 5 = 巽
  • 6 = 坎
  • 7 = 艮
  • 8 = 坤

输出结构

  • 占问
  • 起卦
  • 卦象判断
  • 卦辞原意
  • 爻位分析
  • 时势判断
  • 现实解读
  • 行动建议
  • 一句断语

项目特点

  • 先起卦，再解读
  • 先说本卦、动爻、变卦
  • 不故弄玄虚，不做绝对预言
  • 重点看时势、关系、进退、变化
  • 语言必须落到现实问题

说明

本项目用于文化研究、结构化表达与个人决策参考，不构成法律、医疗、投资等专业意见。
