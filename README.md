# 三数见势｜高岛断事

一个基于“三个数字 + 一个问题”的结构化断事项目。

它的重点不是空谈吉凶，而是根据固定起卦规则，判断事情所处阶段、时势变化、关系节奏，以及下一步更适合怎么推进。

## 使用方式

输入格式：

`三个数字 + 一个问题`

例如：

`3 8 5 我最近要不要换工作？`

## 起卦规则

- 第一个数字定上卦
- 第二个数字定下卦
- 第三个数字定动爻

换算方式：

- 上卦 = 第一个数字 ÷ 8 取余，余 0 按 8
- 下卦 = 第二个数字 ÷ 8 取余，余 0 按 8
- 动爻 = 第三个数字 ÷ 6 取余，余 0 按 6

八卦数对应：

- 1 = 乾
- 2 = 兑
- 3 = 离
- 4 = 震
- 5 = 巽
- 6 = 坎
- 7 = 艮
- 8 = 坤

## 输出结构

- 占问
- 起卦
- 卦象判断
- 卦辞原意
- 爻位分析
- 时势判断
- 现实解读
- 行动建议
- 一句断语

## 项目特点

- 先起卦，再解读
- 先说本卦、动爻、变卦
- 不故弄玄虚，不做绝对预言
- 语言直接、清楚、落地
- 重点看时势、关系、进退、变化
- 解读必须结合现实问题

## 适用场景

- 恋爱与关系推进
- 事业与去留判断
- 投稿、合作、面试、客户沟通
- 人际关系与节奏拿捏
- 当前局势中的进、守、缓、谈、断

## 说明

本项目用于文化研究、结构化表达与个人决策参考，不构成法律、医疗、投资等专业意见。
